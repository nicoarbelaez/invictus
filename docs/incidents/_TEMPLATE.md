# Incidente: \<título corto\>

| Campo | Valor |
|-------|--------|
| **ID** | `YYYY-MM-DD-slug` |
| **Estado** | `open` \| `in_progress` \| `fixed` \| `wontfix` |
| **Área** | `ecommerce` \| `cms` \| `infra` \| `monorepo` |
| **Severidad** | `low` \| `medium` \| `high` |
| **Abierto** | YYYY-MM-DD |
| **Cerrado** | — |

## Problema

Qué falla, dónde se ve, y por qué importa (rendimiento, seguridad, DX, etc.).

## Propuesta

Cómo se debería arreglar. Pasos concretos, trade-offs, y archivos a tocar.

## Cómo se arregló

> Rellenar solo cuando `Estado` = `fixed` (o documentar por qué `wontfix`).

- Qué se cambió
- Archivos / commits relevantes
- Cómo verificar
